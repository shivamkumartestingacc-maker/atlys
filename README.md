# Atlys: Product Design Assignment

This repository is the working space for a product design assignment. It is a sandbox for experiments: layouts, flows, interaction ideas, visual explorations, and prototypes.

## Purpose

- Run design experiments in one place with a clear history.
- Keep each experiment isolated so ideas can be compared, revisited, or discarded.
- Document decisions and reasoning alongside the work.

## Structure

The structure will grow with the assignment. Planned layout:

```
atlys/
├── README.md        # This file: purpose, structure, how to work here
├── experiments/     # One folder per experiment (numbered, e.g. 01-onboarding-flow/)
├── assets/          # Shared images, icons, fonts, and other static files
└── notes/           # Research, decisions, and feedback log
```

## Working Conventions

- **One experiment, one folder.** Name folders `NN-short-name/` (e.g. `03-checkout-variant/`).
- **Each experiment has its own short README** stating the goal, what changed, and the outcome.
- **Commit often.** Small commits with clear messages make the design history readable.
- **Keep failed experiments.** Record why they were dropped in `notes/` instead of deleting them.
- **Assets live in `assets/`.** Do not duplicate them inside experiment folders.
